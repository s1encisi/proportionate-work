# 论文与文档写作规则（按需读取）

文档语言：中文。查看[英文版](writing.en.md)。

适用：README、项目介绍、论文、报告、摘要、结论、汇报材料等文档任务。

## 1. 按文档目的写作

- README 服务于理解和使用；
- 项目介绍服务于说明功能与价值；
- 论文服务于解释研究问题、方法、证据和贡献；
- 审计报告服务于发现和描述实质问题。
不能把所有文档都写成风险评估报告。

## 2. 四类信息的处理

1. 已证实、影响当前使用或结论的问题 → 按必要程度准确表达。
2. 限定结论含义所必需的研究边界 → 按必要程度准确表达。
3. 尚未研究、但不影响当前主张的范围 → 仅在读者需要、用户要求或文体规范要求时说明。
4. 纯粹想象、缺乏依据的潜在缺陷 → 不写入正文。

## 3. 事实边界 ≠ 重复免责声明

- 单一工厂数据的研究，可通过数据来源和研究对象自然界定范围。
- 不在摘要、每节结果、结论和项目介绍中反复补写"尚未证明对所有工厂有效"。
- 如果某项边界直接决定一句结论是否成立，必须保留必要限定，不能移到远处造成误导。

## 4. 有证据就直接陈述

- 对已有证据支持的发现，使用与证据强度一致的明确措辞。
- 不机械插入"仅供参考""尚不成熟""不能保证""可能具有一定潜力"等模糊表达。
- 对未被证明的内容，不编造效果、不扩大适用范围、不把关联写成因果。

## 5. 限制章节的放置

- 同一实质限制在合适位置说明一次即可，除非上下文独立性或规范确实要求重复。
- 用户未要求时，不自动新增局限性、风险、威胁模型、已知问题等章节。
- 用户明确要求审稿、问题诊断、局限性分析或风险审计时，认真完成相关分析；本技能不是回避批评的理由。

## 6. 修订服务于具体目标

- 按用户要求修改内容、逻辑、表达或格式。
- 达到目标后停止，不为追求无法定义的"更严谨""更完美"反复整篇重写。
- 不擅自删除原文中已有价值且真实的限制说明，也不扩大它们的严重程度。
